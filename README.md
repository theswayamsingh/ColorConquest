
# 🌈 Color Conquest : Color Game

- Available on the Google Play Store, with a growing user base.
- Features progressively challenging levels to test players’ speed and accuracy in identifying color-based patterns.
- Integrated Google AdMob to run ads and generate in-app revenue.
- Developed with a focus on smooth performance, cross-device compatibility, and minimal latency in touch responses.
- Designed a vibrant and intuitive UI to attract users of all age groups.
- Incorporated feedback mechanisms to collect user suggestions for continuous gameplay improvement.

## 🛠️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/theswayamsingh/ColorConquest.git
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```
